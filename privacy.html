墨读 MoRead

隐私政策

最后更新：2026 年 11 月 14 日

一句话版本：墨读不收集你的任何个人信息。书架、书源、阅读进度和备份都只存在你自己的设备上，我们没有服务器，也没有账号系统。

1. 我们收集什么

不收集。墨读没有注册、登录、统计 SDK 或广告 SDK，不会上传设备信息、位置、通讯录、剪贴板或阅读记录。

2. 数据存在哪里

  • Windows / macOS / Linux：默认在系统的应用数据目录（如 %APPDATA%\墨读）；如果程序目录里有 portable.txt，则写在程序旁边的 data/。
  • Android / iOS / 鸿蒙：应用私有目录，卸载即删除。
  • 网页版：浏览器本地存储（IndexedDB / localStorage）。

这些数据只有你能访问，开发者看不到，也无法远程读取或恢复。

3. 什么时候会联网

  • 书源搜索与正文：请求你自己导入的书源站点。请求内容取决于书源规则，与墨读开发者无关。
  • 网页搜书：请求你选择的搜索引擎。
  • 云端备份：只有你在「设置 → 云端同步」里填了 WebDAV 地址并启用后，才会连接你自己的网盘。
  • 检查更新：只有你点「检查更新」时，才会向 GitHub / Gitee 的公开接口读取最新版本号，不发送任何设备标识或使用数据。
  • 本地导入：解析本地书籍、生成封面缩略图都在本机完成，不上传文件。

4. 第三方

应用本身不集成第三方统计或广告服务。你在应用内打开的第三方网页（书源站点、开源仓库、作者公众号/抖音）受各自隐私政策约束。

5. 儿童隐私

墨读不面向儿童收集任何信息，也不包含社交、支付或用户生成内容功能。

6. 你的控制权

你可以随时在「设置 → 数据与备份」导出或删除全部数据；卸载应用会删除应用私有目录中的内容。

7. 政策变更

如果未来功能变化导致本政策调整，会更新本页顶部的日期，并在应用内说明。

8. 联系方式

问题或建议：GitHub Issues · Gitee Issues
