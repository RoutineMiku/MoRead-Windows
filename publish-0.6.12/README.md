# 墨读 0.6.1 → 0.6.12 发布素材

两个平台的成品都在这里，打开即用，不需要再处理图片。**公众号文章里已经附上了安装包**：一个下载落地页 + 二维码，读者扫码按设备点一下就装。

```
publish-0.6.12/
├─ douyin/                 抖音图文
│   ├─ dy-01.png … dy-11.png   1080×1920，按序号上传（第 11 张是下载卡）
│   ├─ download-qr.png         下载页二维码（备用）
│   └─ 文案.md                 标题 + 描述 + 话题 + 评论区置顶
└─ wechat/                 公众号
    ├─ article-inline.html     正文（图片已内嵌，打开后全选复制 → 粘贴进编辑器）
    ├─ article.html            同一篇，图片走 img/，供改稿与脚本读取
    ├─ publish-draft.js        一键发草稿箱（自动传封面/正文图 + 设阅读原文）
    ├─ cover-900x383.png       封面 1800×766
    ├─ img/                    正文配图（含 download-qr.png）
    └─ 文案.md                 标题 + 摘要 + 阅读原文 + 两种发布方式
```

## 下载落地页（已上线）

**https://routinemiku.github.io/MoRead-Windows/download.html**

源码 `web/download.html`，由 `build/gen-web.js` 复制进 `dist-web/`，随 `web/deploy-pages.js` 发布到 Pages。页面按设备列出九个平台安装包的直链（指向 GitHub Release v0.6.12），还有网页版入口与安装提示。公众号文章里的二维码、抖音第 11 张的二维码、公众号「阅读原文」全都指向这一页。

> 公众号正文里塞不进 140MB 的压缩包，所以走「下载页 + 二维码 + 阅读原文」这三件套，等价于是把安装包附在文章里；安卓 APK 只有 4.5 MB，手机上点一下就下。

## 抖音怎么发

创作服务平台 → 发布图文 → 依次选中 `dy-01` 到 `dy-11` → 标题填「十一天，把阅读器改到九个平台」→ 描述从 `douyin/文案.md` 复制 → 发布 → 按文案里的地址置顶一条评论。

## 公众号怎么发

**推荐**：有 API 权限时在 `wechat/` 下跑

```bash
WECHAT_APP_ID=wxXXXX WECHAT_APP_SECRET=XXXX node publish-draft.js
```

自动传封面与 9 处正文配图、写好标题/作者/摘要/「阅读原文」，落到草稿箱。

**或者手动**：浏览器打开 `wechat/article-inline.html`，全选复制粘贴进编辑器（图片自动转存微信图床）；封面用 `cover-900x383.png`，作者 `routinemiku`，「阅读原文」填下载页地址。
