## 怎么发

### 方式 A：一键发到草稿箱（推荐，有 API 权限时）

```bash
cd publish-0.6.12/wechat
WECHAT_APP_ID=wxXXXX WECHAT_APP_SECRET=XXXX node publish-draft.js
```

脚本会自动上传封面 + 9 处正文配图、填好标题/作者/摘要/「阅读原文」、写入草稿箱，最后打印 `media_id`。确认无误后在公众号后台点发布即可（加 `--publish` 参数则由接口直接提交群发）。

前提：公众号后台 → 开发 → 基本配置 拿到 AppID / AppSecret，并把本机公网 IP 加进 **IP 白名单**（否则报 40164）。未认证订阅号没有草稿箱接口，走方式 B。

### 方式 B：手动粘贴

1. 用浏览器打开 **`article-inline.html`**（图片已 base64 内嵌，不需要单独上传）
2. 从大标题「十二个版本，从一屏 17 行」全选到最后的「左：扫码关注　右：扫码下载」
3. 粘贴进公众号编辑器正文区 —— 图片会自动上传到微信图床
4. 封面选 **`cover-900x383.png`**（2.35:1）
5. 作者 `routinemiku`，摘要用上面那段，「阅读原文」填上面那条下载页地址

> 公众号编辑器是 ProseMirror，直接改 HTML 无效，必须走「复制粘贴」；
> 图片用 data: URL 内联粘贴，编辑器会自动转存，这是最省事的方式。
