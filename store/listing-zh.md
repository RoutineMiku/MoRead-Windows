# 微软商店文案（zh-CN）

Partner Center → 应用 → 商店列表，按下面对应字段粘贴。截图在 `store/screenshots/`。

## 应用名称（Product name）

```
墨读
```

> 先在 Partner Center「应用名称」里预留 `墨读`。如果被占用，备选：`墨读 MoRead`、`墨读阅读器`。

## 简短描述（Short description，建议 ≤ 200 字符）

```
本地优先的开源阅读器：支持 EPUB / TXT、Legado 书源、换源与朗读。书架、进度、备份只存在你的设备上，不上传、不追踪，免费无广告。
```

## 详细描述（Description）

```
墨读是一个本地优先的阅读器。书架、书源、阅读进度和备份都只存在你自己的设备上——没有账号、没有云端、不上传、不追踪。

■ 能读什么
· EPUB、TXT、本地文件夹导入，自动分章、生成目录
· 兼容 Legado（开源阅读）书源的 JSON 规则，可导入现成书源
· 支持网页搜书与书源搜索两种找书方式

■ 读起来怎么样
· 字号、行距、段距、字体、翻页方式都能调，改动即时生效
· 滚动 / 翻页两种模式，翻页时左右轻点即可
· 深色模式、护眼配色，长时间看不刺眼
· 系统语音朗读，可自动读下一章

■ 数据在自己手里
· 进度、书签、批注都存在本机
· 一键导出备份 zip，原版「阅读」也能直接导入
· 可选坚果云 / WebDAV 自动备份到自己网盘
· 卸载前导出即可完整搬走

■ 开源
· 同一套界面跑在 Windows、macOS、Linux、Android、iOS、鸿蒙和网页
· 代码公开在 GitHub / Gitee，免费、无广告、无内购

■ 适合谁
习惯自己管书、自己配书源、不想把阅读记录交给任何平台的人。
```
