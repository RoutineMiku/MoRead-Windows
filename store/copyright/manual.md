墨读（MoRead）软件说明书
版本：V0.6.13　　著作权人：RoutineMiku

一、软件概述
墨读是一款本地优先的开源电子书阅读器。它把书架、书源规则、阅读进度与备份全部
保存在用户本机，不需要注册账号，不上传任何数据，不追踪用户行为。同一套界面与
数据格式覆盖 Windows、macOS、Linux、Android、iOS、鸿蒙与网页七端。软件采用
MIT 许可证开源，免费、无广告、无内购。

二、运行环境
· 操作系统：Windows 10 1809+ / macOS 11+ / 主流 Linux（含统信 UOS、deepin）/
  Android 8.0+ / iOS 15+ / HarmonyOS NEXT
· 内存：4 GB 及以上　· 存储：400 MB 可用空间
· 联网：仅在用户主动使用「书源搜索 / 网页搜书 / 检查更新」时需要

三、功能模块与操作说明
（下列每个模块配 1–2 张界面截图，截图见 store/screenshots/）

1. 书架管理（截图：01-shelf.png）
   导入本地 EPUB、TXT 文件或整个文件夹；自动生成封面与目录；顶部「继续阅读」
   卡片显示上次阅读进度，点击直接回到上次位置。支持搜索、分组、批量删除。

2. 阅读器（截图：02-reader.png）
   分页 / 滚动两种模式；左右轻点翻页；字号、行距、段距、字体、翻页动画实时可调；
   深色模式与多种护眼配色；阅读进度、书签、批注自动保存到本机。

3. 书源与找书（截图：03-search.png）
   兼容 Legado（开源阅读）书源 JSON 规则，可导入现成书源；支持「书源搜索」与
   「网页搜书」两种方式；同一本书可一键换源，自动续读。

4. 语音朗读
   调用系统语音合成朗读当前章节，可自动连读下一章；语速、音色可调。

5. 扩展（截图：05-ext.png）
   书源管理、历史记录、阅读统计集中入口；开发者可将自研面板（JSON / HTML）
   导入扩展菜单，运行在沙箱 iframe 中，通过 postMessage 与主程序通信。

6. 设置（截图：04-settings.png）
   阅读、朗读、书架、搜索与网络、数据与备份、云端同步、系统、关于八个模块的
   二级菜单；「关于」页含版本号与「检查更新」，同时查询 Gitee 与 GitHub 的
   最新版本。

7. 数据与备份
   一键导出 zip 备份，原版「阅读」App 也能直接导入；可选坚果云 / WebDAV
   自动备份到用户自己的网盘；卸载前导出即可完整迁移全部数据。

四、技术特点
· 跨端同构：ui/ 目录为七端共用的同一套 HTML/CSS/JS，桌面端与安卓端仅各自
  维护一份宿主桥接层，最大限度减少平台差异。
· 本地优先：所有数据只存本机，不依赖任何后端服务，断网可正常阅读。
· 开源可审计：源代码公开于 GitHub（RoutineMiku/MoRead-Windows）与
  Gitee（daily-miku/moread）。
